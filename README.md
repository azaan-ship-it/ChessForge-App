# ChessForge

Play chess online, battle 24 bots with real personalities, join tournaments and clubs, solve puzzles,
and get free, unlimited game reviews. By ByteForge Studios.

## Play in your browser

**https://playchessforge.onrender.com**

The first load can take about a minute while the server wakes up. After that it's fast.

## Download for Windows

Get **ChessForge-Setup-1.0.0.exe** from the [latest release](https://github.com/azaan-ship-it/ChessForge-App/releases/latest)
and run it.

Windows may show a SmartScreen warning because the installer isn't signed yet. Click **More info → Run anyway**.

## Features

- **Play online:** rated Bullet, Blitz, Rapid and Daily games, or play friends in a private room with a PIN.
- **24 bots:** from beginner to grandmaster, each with its own style and trash talk.
- **Tournaments:** arena and Swiss events, plus ones you create yourself.
- **Clubs:** chat, leaderboards, club tournaments and club-vs-club matches.
- **ChessForge TV:** watch the best live games.
- **Puzzles:** rated puzzles, a daily puzzle, Puzzle Rush and Puzzle Battle.
- **Learn:** interactive lessons from the basics to endgames.
- **Free unlimited game review:** accuracy scores, move labels and "retry your mistakes."
- **Progress:** achievements, streaks, leaderboards, and board themes and piece sets you unlock by playing.
- **Offline mode** in the Windows app: bots, puzzles, lessons and analysis work without internet.
